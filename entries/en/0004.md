# What's new in June 2026

A roundup of recent improvements across the platform — new features, polish, and fixes.

## New features

### Video editor soft redesign

The video editor has a refreshed design, with a new **Scenes + Layers** left panel that makes navigating complex projects far easier. Item settings have moved into clean side panels for a less cluttered editing surface.

### Disable intro and outro

You can now turn off the intro and/or outro of a video directly from the video editor — useful when you want to drop straight into the main content.

### Add and remove slides in Flash projects

The video editor now lets you add and remove slides on Flash projects, bringing the same flexibility you already had on other project types.

### New Script tab editor

The old voiceover cards have been replaced with a unified **Script** tab editor — a single, focused place to write and edit your script.

### Revamped Playbooks UI

Playbooks have a brand-new interface that makes browsing, organizing, and reusing your templates much easier.

### HubSpot connection

You can now connect Libertify to **HubSpot**, syncing your projects and audience data directly with your CRM.

### SCORM advanced features

SCORM packages now support advanced learning features, including **completion based on watched coverage**, exact resume points, and hardened delivery for more reliable LMS integration.

### Mobile-friendly sidebar

The sidebar menu now adapts to mobile, giving you a smoother navigation experience on smaller screens.

## Improvements

### Smoother slides streaming

A round of fixes makes streaming slides faster and more reliable, especially on larger projects.

### Storyboard editor refinements

The storyboard editor has received a series of usability improvements, making it feel quicker and more intuitive to work with.

### Cleaner Playbook list

Auto-generated brandkits are now hidden from the Playbook view, keeping the list focused on the brand kits you actually curated.

### Script button hidden for Flash projects

The Script editor button is now hidden in settings for Flash projects, where it doesn't apply.

### Helpful storyboard wait message

If a storyboard is taking longer than expected to appear, you'll now see a friendly message explaining what's going on, instead of an empty screen.

### Tidier text saving

Text saved in the storyboard is now automatically trimmed of stray whitespace, keeping captions and titles clean.

### User menu matches sidebar style

The user menu has been restyled to align visually with the new sidebar, for a more consistent overall look.

### Main image treated as a regular media item

The storyboard main image now behaves like any other media item, making edits and replacements more predictable.

## Fixes

- **Video editor no longer hangs** on projects without a presenter.
- **Chat now displays correctly** when a document is toggled off.
- **Color picker gradient mode** no longer crashes when the main color has opacity.
- **Language picker** no longer scrolls back to the top after you make a selection.
- **Chapter templates without a subtitle item** now render correctly instead of failing silently.
- **Storyboard approval & regenerate media flows** have been hardened to avoid intermittent errors.
- **Video editor no longer makes unexpected requests** to the asset library on load, improving performance.
- **Resilience fix** for an occasional crash when API responses arrived in an unexpected shape.
