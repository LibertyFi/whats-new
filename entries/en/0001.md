# What's new in May 2026

A roundup of recent improvements across the platform — new features, polish, and fixes.

## New features

### New Official Themes

Several themes were added, Autopilot can now automatically select from those upon experience generation.

### Product updates page

A new Customer Updates page is now available in the app, pulling the latest product news directly from our external updates feed — so you can stay on top of new features and improvements without leaving Libertify.

### Script button restored for custom projects

The Script button is back for custom projects, and default script handling has been tightened so your starting content is always what you expect.

### Hey Genius now works inside documents

Invoke Hey Genius directly from within your documents, with a new video-only mode and faster overall performance.

### Playbook selector in the project wizard

Template Settings have been renamed to **Playbooks** across the app to better reflect their role. Choose a playbook directly while creating a project.

### Action Required status badge

Projects that need your attention now show a clear **Action Required** badge in the project list, so nothing slips through the cracks. They were previously shown as "In Progress" causing some confusion.

### Analytics shortcut in the experience editor

A dedicated **Analytics** button is now available in the experience editor, with nearby controls reorganized for easier access.

### Aspect ratio in themes

Themes now include an aspect-ratio setting, making it easier to tailor video output for specific platforms (vertical, square, landscape).

### Smarter voice profile list

The premade voice profile list now automatically syncs with the language filters you've selected, so you only see voices relevant to your project.

### Optional default theme

Organization settings now let you select **no default theme** — useful when you'd rather pick a theme per project.

## Improvements

### Tools brought to the top

Key editing tools are now anchored at the top of the workspace, making them faster to reach while you work on a project.

### Faster, more reliable voice previews
Voice preview audio now loads through a single consolidated pipeline, making previews quicker, smoother, and more consistent across the app.

### Cleaner maintenance messaging

Maintenance error messages have been refined and no longer flicker on screen during recovery, for a calmer, less jarring experience when things go wrong.

### Calls-to-action moved to the top of experiences

CTAs now appear at the top of an experience, making them far more visible to your viewers.

### Cleaner published experiences for paid plans

The experience page footer is now hidden for paid plans, giving your published content a more polished, branded look.

### Better mobile-format video sizing

Mobile-format videos now scale width to use the maximum available height, giving viewers a fuller view on phones.

### More visible zoom controls

Zoom controls in the storyboard editor are now more prominent and easier to find.

### Refreshed responsive layout

The base width of the left panel has been adjusted for a more balanced default experience.

### Smoother popup styling

Popups have a cleaner appearance (no more green tint), and dismissed popups now stay dismissed.

### Always-fresh project list

Your projects list refreshes automatically when you return to it, so the latest changes always show up.

## Fixes

- **CTAs are now locked on published experiences** — prevents accidental edits to live content.
- **Generate Video disabled on published projects** — the button is now correctly disabled in the storyboard editor when a project has already been published.
- **Paywall no longer flickers** on initial load.
- **Divider lines on bullet-point slides** are now saved correctly.
- **Voices carousel on the avatar creation screen** — fixed a bug where some voices wouldn't appear.
- **Minor color correction** in published experience styling.
- **Better project timestamps** - Project timestamps now classify correctly (e.g. "yesterday", "last week"), with refined French translations.
- **Welcome modal no longer shown to existing users** — the onboarding modal now only appears for genuinely new users, not for those who already have projects.
- **Document highlighter "Modify all"** — color updates are now applied correctly across all highlighted items in one go.
- **Voice not ready error** — fixed an error that appeared when previewing voices without an existing preview asset.
- **Paywall** no longer flashes on initial load.
- **Chatbot resize fixed** — you can now widen the chatbot panel to the right as expected.
- **Avatar rendering in the video editor** — fixed a visual glitch when displaying avatars in the editor.
- **Safer CTA creation** — added guards to prevent invalid states when creating calls-to-action.
- **Cloning modal locked during cloning** — the voice cloning modal can no longer be accidentally dismissed while a clone is in progress, preventing interrupted jobs.
