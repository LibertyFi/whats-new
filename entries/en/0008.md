# What's new in August 2026

A roundup of recent improvements across the platform — new features, polish, and fixes.

## New features

### Password change flow

You can now change your password directly from the app, through a new dedicated flow.

### Redesigned 404 pages

The **404 pages** in both admin and media-player have been redesigned, with clearer wording for unpublished experiences so viewers know what happened.

### LTI upload flow

A new **LTI upload flow** automatically creates a project with the default public playbook when uploading from your LMS — a huge shortcut for teachers.

## Improvements

### Live feedback on experience loading

Experience loading now uses **websockets, toasts, and spinners** to give clear, live feedback as your content assembles — no more wondering what's happening in the background.

### Cleaner video playback experience

On video play, the header now retracts, leaving only the video and document panels for a more immersive viewing experience.

### Avatar controls in the video editor

- The **avatar visibility** settings UI in the video editor is clearer and easier to use.
- You can now **edit avatar details** directly from the storyboard's avatar modal.
- **Apply avatar styles** buttons are back.

### Smoother experience creation

The **Create experience** button now stays in its loading state until navigation completes, so you know your action registered.

### BrandKit polish

- The **BrandKit preview** is now scrollable on small screens.
- New brandkit logos with different widths are now centered correctly.

### Share modal

The **Restricted access** option has been removed from the experience-v2 Share modal to keep sharing options focused on what's actually supported.

### Better aspect ratio labeling

The video configuration aspect-ratio picker now shows **Tablet** instead of the ambiguous "Square" label.

### Audio playback resilience

If a playable audio track is available, it now wins over the audio tab's error state, so viewers hear what they should hear.

### Migrated to per-instance publication

Experiences now use a new **per-instance publication mechanism**, unlocking more flexible sharing and distribution down the line.

## Fixes

- **Transition template no longer contains a Chapter template** — fixes a rare mix-up when generating videos.
- **Whole-script editing** now splits cleanly by slide in the storyboard editor.
- **Change avatar modal** now selects the correct avatar (including voice-only avatars).
- **Voice-only avatars** are set correctly in the video editor.
- **TTS requests** always include the section ID so the backend picks the right avatar voice.
- **Summary Settings** no longer error out with a 422 on save.
- **"Create Now" component** no longer hides content behind it.
- **LTI sessions** aren't logged out on recoverable 401s.
- **LTI deep link** no longer gets stuck on a spinner after a token race on first login.
- **Teacher onboarding order** — the LTI deep link page no longer briefly flashes onboarding before the creator profile resolves.
- **Removing the AI chat add-on** in the new experience flow now works.
- **Empty scenes on Flash education projects** in edit mode have been fixed.
- **Collapsing a Knowledge Hub or Chatbot panel** no longer resets both.
- **Video playback highlights** are now painted correctly in experience-v2.
- **Document skeleton** is shown while loading instead of flashing an error card.
- **Bookmarks tab** is now hidden in sales and admin's experience-v2 viewer where it doesn't apply.
