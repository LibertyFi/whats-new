# What's new in November 2026

A roundup of recent improvements across the platform — new features, polish, and fixes.

## New features

### Viewer progress table

The Viewers tab of your project analytics now shows a **viewer table** instead of an activity feed:

- Each row is one viewer, with when they last viewed, their read depth, chats and interest, then the video and one column per add-on the project uses.
- Sort by any column, search by email, filter with the All, Opened, Not opened and Quiz pills, and choose the columns to show with Table fields.
- Pick a version to update the add-on columns, and export a zip with one CSV file per add-on.

### Choose your organization's add-ons

Organization owners now have an **Add-ons** item in the organization preferences, with a switch for each add-on in your plan. Add-ons you turn off are no longer offered when you create an experience, build a playbook or add an add-on to an experience. Add-ons already on an experience stay listed, so you can still reorder or hide them.

## Improvements

### Why a document was rejected

When an uploaded document is rejected, the studio, the project page and the experience page now tell you **why**: the file is too large, uses protected fonts, couldn't be converted, or didn't pass the security check. A missing document is also explained instead of offering to regenerate.

## Academics

### Download your video and podcast

The Video and Podcast tabs of the new experience page now have a **Download** button that opens the file in a new tab.

## Fixes

- **Unsaved changes after a long session** — your sign-in is now renewed before it expires, so changes such as deleting a scene are no longer lost.
- **Access settings** — when you change access or the list of authorized emails several times in a row, your latest choice is now the one saved.
- **Experience page reloads** — reloading an experience page no longer sometimes ends on an error screen.
- **Sign-in loop** — the app no longer reloads endlessly when your account details fail to load.
- **Intro and closing scenes** — edits such as Set as background on intro and closing scenes are now saved in the video editor.
- **General settings when creating an experience** — the card no longer spins forever with an error message when voices, brand kits or preferences fail to load; the form now opens anyway.
- **Avatar voice previews** — the avatar edit page no longer looks like it reloads while a voice preview is being prepared.
- **Video analytics** — the Video tab now appears for projects whose video was made without an avatar or uploaded.
