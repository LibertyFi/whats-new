# What's new in September 2026

A roundup of recent improvements across the platform — new features, polish, and fixes.

## Improvements

### Cleaner highlight marks

Chatbot citations and Standout marks on the new experience page now render as **clean, straight highlights** instead of hand-drawn strokes, and tiny marks that rendered incorrectly are no longer shown.

## Fixes

- **Tutorial videos** now play inside the Tutorials page.
- **Analytics page** no longer crashes when insights arrive in an older data format.
- **Call-to-action links** on the Edit experience page no longer lose a newly added row while a previous save is in progress, and quick successive saves no longer create duplicates.
